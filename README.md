# claude-statusline-astro

Claude Code 화면 아래에 **지금 상태를 한 줄로** 보여 주고, 프롬프트 아래에 **내 마스코트**를 앉혀 둡니다.

![상태라인 예시](docs/use.png)

- 작업 중인 폴더, git 브랜치, 쓰는 모델, 대화가 얼마나 찼는지, 5시간 한도가 얼마나 남았는지 한 줄로 보입니다.
- 마스코트는 하루에 한 번 뽑는 얼굴입니다. 일하는 동안 표정이 바뀌고, 지금 하는 일을 말해 주거나 넌센스 퀴즈를 내기도 합니다. 등급이 높을수록 말솜씨가 좋습니다.
- 마스코트는 말랑말랑한 아기 동물과 정령들입니다. 가장 드문 레전드 다섯은 저마다 다른 효과(무지개 숨결, 번개 속 박쥐, 천둥 번개, 활활 불꽃, 오로라)로 움직입니다.
- Windows, macOS, Linux 어디서나 같은 모양입니다.
- 토큰을 쓰지 않습니다. 화면에 그리는 것과 명령 모두 Claude를 거치지 않습니다.

> 개인이 만든 프로젝트입니다. Anthropic과는 관계가 없습니다.

## 1. 설치

### Claude Code 안에서 (추천)

Claude Code를 열고 채팅창에 아래 세 줄을 **한 줄씩** 입력합니다.

```
/plugin marketplace add black-astro/claude-statusline-astro
```
```
/plugin install statusline@black-astro
```
```
/statusline-install
```

이 방법으로 설치해야 마스코트가 프롬프트 아래에서 **부드럽게 반짝이고**, 아래의 `/statusline-...` 명령들을 쓸 수 있습니다. 플러그인은 한 번만 설치하면 모든 세션과 프로젝트에 적용됩니다(설치할 때 범위는 `user`).

이미 열려 있는 다른 콘솔은 `/reload-plugins`를 입력하거나, 껐다가 `claude --continue`로 다시 열면 적용됩니다.

### 터미널에서

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/black-astro/claude-statusline-astro/main/install.ps1 | iex
```

macOS, Linux, WSL:

```sh
curl -fsSL https://raw.githubusercontent.com/black-astro/claude-statusline-astro/main/install.sh | sh
```

터미널 설치만 하면 상태줄과 마스코트가 나오지만, 마스코트는 상태줄 끝에서 2초에 한 번씩 바뀌고 `/statusline-...` 명령은 없습니다(뽑기는 `mascot` 명령으로 합니다). 반짝이는 마스코트와 명령도 쓰려면 위의 `/plugin` 두 줄을 이어서 입력하세요.

### 설치한 다음

**Claude Code를 완전히 닫았다가 다시 여세요.** 그래야 줄과 마스코트가 나타납니다.

설치는 홈 폴더의 `.claude` 폴더 안에서만 이루어집니다. 스크립트 몇 개가 복사되고 `settings.json`에 필요한 항목이 더해집니다. 원래 설정은 그대로 두고, `settings.json.bak`으로 백업도 남깁니다.

| 운영체제 | 홈 폴더의 `.claude` |
| --- | --- |
| Windows | `C:\Users\사용자이름\.claude\` |
| macOS | `/Users/사용자이름/.claude/` |
| Linux | `/home/사용자이름/.claude/` |

아래에서 `~/.claude/`라고 적힌 곳은 모두 이 폴더입니다.

## 2. 처음 쓰기

1. 설치하고 Claude Code를 다시 엽니다. 화면 아래에 상태줄이 보이면 성공입니다.
2. 마스코트를 뽑습니다. 처음에는 마스코트가 없습니다.
   ```
   /statusline-roll
   ```
3. 프롬프트 아래 오른쪽에 마스코트가 앉습니다. 아무 질문이나 보내 보세요. 작업하는 동안 표정이 바뀌고 한마디 합니다.

위치가 마음에 들지 않으면 [위치 고르기](#어디에-앉을지-고르기)에서 바꿀 수 있습니다.

## 3. 마스코트

### 뽑기

```
/statusline-roll
```

```
오늘의 마스코트를 뽑았습니다!

  뿅!
  ʕ˶◐ᴥ◑˶ʔ  Panda  [레어 1/4]
  "냠냠! 나는 Panda, 판다예요!"
  표정 2장  ʕ˶◐ᴥ◑˶ʔ ʕ˶●ᴥ●˶ʔ

다음 뽑기는 내일부터 가능합니다.
```

- 뽑기는 **하루에 한 번**입니다.
- 뽑지 않으면 지금 얼굴이 **그대로** 남습니다. 저절로 바뀌지 않습니다.
- 어떤 프로젝트, 어떤 터미널, 새로 연 세션에서도 **같은 얼굴**이 나옵니다.
- 얼굴마다 영어 이름이 있습니다. 지금 얼굴과 이름은 `/statusline-today`로 봅니다.

### 어디에 앉을지 고르기

```
/statusline-place right
```

| 값 | 위치 |
| --- | --- |
| `right` | 프롬프트 아래 오른쪽 (기본) |
| `left` | 프롬프트 아래 왼쪽 |
| `above` | 프롬프트 바로 위 |
| `line` | 상태줄 끝 (예전 방식, 2초에 한 번씩 바뀜) |

한 번 고르면 다음에 열 때도 그 자리에 앉습니다. 값 없이 `/statusline-place`만 입력하면 지금 위치를 알려 줍니다.

프롬프트 아래 자리는 플러그인으로 설치하고, Claude Code가 최신 버전(2.1.296 이상에서 확인)일 때 나옵니다. 그렇지 않으면 마스코트는 상태줄 끝에 나옵니다.

### 마스코트가 말할 때

평소에는 얼굴만 있습니다. 네 순간에만 한마디 합니다.

| 순간 | 예 (레전드) |
| --- | --- |
| Claude가 작업하는 동안 | `하나도 빠짐없이 챙기는 중이에요` |
| 작업이 막 끝났을 때 (1분 동안) | `다 됐어요, 확인해 줄래요?` |
| 확인을 기다릴 때 | `잠깐 확인해 줄래요?` |
| 작업이 실패했을 때 | `문제가 생겼어요… 같이 살펴봐 줄래요?` |

작업하는 동안에는 이렇게 움직입니다.

- 표정이 2초마다 바뀝니다. 눈을 깜빡이거나 웃는 얼굴이 되고, 귀와 앞발은 그대로입니다.
- 대사가 10초마다 바뀝니다.
- 넌센스 퀴즈를 내고, 5초 뒤에 정답을 말합니다.
- 대사는 얼굴 오른쪽에 한 칸 띄워서, 깜빡임 없이 한 가지 색으로 나옵니다.
- 레어 이상은 지금 하는 일도 알려 줍니다. 파일을 읽는 중인지, 코드를 고치는 중인지, 명령을 실행하는 중인지 말합니다.

모두 귀여운 아기 동물 친구 말투이고, 등급이 높을수록 말을 잘합니다.

| 등급 | 말투 |
| --- | --- |
| 커먼 | 짧고 귀여운 한마디 (`영차영차!`, `헤헤, 완성!`) |
| 언커먼 | 수다스러운 친구, 짧은 넌센스 |
| 레어 | 또박또박, 하는 일 알려 주기, 넌센스 |
| 유니크 | 자신감 있게, 더 꼼꼼한 설명 |
| 레전드 | 가장 말을 잘함, 넌센스를 바로 냄 (`물고기의 반대말은?` … `불고기!`) |

프롬프트 아래 자리에서 그렇습니다. 상태줄 끝(`line`)에 둘 때는 예전처럼 상황마다 한 줄만 말합니다.

## 4. 명령어

모든 명령은 Claude를 거치지 않고 바로 실행됩니다. 토큰이 들지 않고, Claude가 일하는 중에도 바로 됩니다. 플러그인으로 설치하고 Claude Code가 최신 버전(2.1.296 이상에서 확인)일 때 쓸 수 있습니다.

| 입력 | 하는 일 |
| --- | --- |
| `/statusline-roll` | 마스코트 뽑기 (하루 한 번) |
| `/statusline-today` | 지금 내 마스코트와 이름 보기 |
| `/statusline-place` | 마스코트 위치 보기·바꾸기 |
| `/statusline-mode` | 정보 줄을 그리는 방식과 위치 보기·바꾸기 ([앱 모드](#앱-모드)) |
| `/statusline-update` | 상태줄 스크립트를 최신으로 (설정은 그대로) |
| `/statusline-install` | 설치, 재설치 |
| `/statusline-help` | 짧은 도움말 |

명령이 안 보이는 환경(예전 Claude Code, 터미널 설치만 한 경우)에서는 터미널에서 뽑고 볼 수 있습니다.

```sh
# macOS · Linux · WSL
~/.claude/mascot roll        # 뽑기
~/.claude/mascot             # 지금 마스코트
```

```powershell
# Windows
~\.claude\mascot.cmd roll    # 뽑기
~\.claude\mascot.cmd         # 지금 마스코트
```

## 5. 화면 읽는 법

```
DIR my-project | GIT main | MODEL opus5.5 | EFFORT H | CTX [◼◼◻◻◻◻◻◻◻◻] 21% | 5H [◼◼◼◻◻◻◻◻◻◻] 34% 1h49m
```

| 항목 | 뜻 |
| --- | --- |
| `DIR` | 작업 중인 프로젝트 폴더 |
| `GIT` | 브랜치. `main`과 `master`는 보라색, 나머지는 하늘색 |
| `MODEL` | 쓰는 모델. `opus5.5`처럼 이름과 버전만 짧게 |
| `EFFORT` | 생각하는 정도(effort). `L` low · `M` medium · `H` high · `XH` xhigh · `U` max. `/effort`로 바꾸면 따라 바뀝니다 |
| `CTX` | 대화가 얼마나 찼는지. 100%에 가까워지면 앞쪽 대화가 정리됩니다 |
| `5H` | 5시간 사용 한도. 뒤의 `1h49m`은 한도가 새로 시작되기까지 남은 시간 |

게이지는 60% 미만이면 초록, 60% 이상이면 주황, 90% 이상이면 빨강입니다.

`CTX`는 세션마다 따로 셉니다. `5H`는 계정 전체가 함께 쓰는 값이라 어느 터미널에서나 같습니다. 잠깐 뒤처진 값 앞에는 `~`가 붙고, 메시지를 보내면 맞춰집니다.

## 6. 마스코트 도감

얼굴은 **23종**, 다섯 등급입니다. 확률은 누구에게나 같습니다.

| 등급 | 확률 | 색 | 얼굴 수 |
| --- | --- | --- | --- |
| 커먼 | 25% | 옅은 회색 | 6 |
| 언커먼 | 30% | 연한 초록 | 5 |
| 레어 | 25% | 하늘색 | 4 |
| 유니크 | 15% | 보라 · 작은 장식 하나 | 3 |
| 레전드 | 5% | 저마다 다른 효과로 움직임 · 장식 최대 두 개 | 5 |

예전 버전에서 뽑아 둔 얼굴은 같은 등급의 새 얼굴로 바뀌어 그대로 이어집니다.

## 7. 옵션과 앱 모드

`~/.claude/settings.json`의 `env` 항목에 넣고 Claude Code를 다시 열면 적용됩니다. 예를 들어 대사 없이 얼굴만 보려면 이렇게 씁니다.

```json
{
  "env": {
    "STATUSLINE_TALK": "0"
  }
}
```

| 변수 | 값 | 하는 일 |
| --- | --- | --- |
| `STATUSLINE_MASCOT` | `0` | 마스코트 숨기기 |
| `STATUSLINE_TALK` | `0` | 얼굴만, 대사 없이 |
| `STATUSLINE_SEVEN_DAY` | `1` | 주간(7일) 사용 한도 게이지 표시 |
| `STATUSLINE_EFFORT` | `0` | `EFFORT` 숨기기 (기본은 보임) |
| `STATUSLINE_TRUE_COLOR` | `0` | 256색만 되는 터미널에서 상태줄 끝 레전드 색 맞추기 |
| `NO_COLOR` | `1` | 색 전부 끄기 |

`settings.json`에 이미 `env`가 있다면 그 안에 줄만 더하면 됩니다. 마스코트 위치는 옵션이 아니라 `/statusline-place`로 고릅니다.

### 앱 모드

평소에는 상태줄 스크립트가 1~2초마다 실행되며 정보 줄을 그립니다. 앱 모드를 켜면 정보 줄(`DIR`, `GIT`, `MODEL`, `EFFORT`, `CTX`, `5H`)까지 플러그인이 Claude Code 안에서 직접 그리고, 스크립트는 더 이상 실행되지 않습니다.

```
/statusline-mode app          켜기 (정보 줄은 프롬프트 바로 위)
/statusline-mode app below    켜기 (정보 줄은 프롬프트 아래)
/statusline-mode script       끄기 (원래대로)
```

| | 스크립트 (기본) | 앱 모드 |
| --- | --- | --- |
| 정보 줄 위치 | 상태줄 | 프롬프트 바로 위 한 줄 (`below`면 프롬프트 아래) |
| 컴퓨터 부담 | 스크립트가 계속 실행됨 | 거의 없음 |
| 값이 바뀌는 속도 | 1~2초마다 | 2초마다, 작업이 끝나면 바로 |

- 특히 Windows에서는 PowerShell이 계속 뜨지 않아서 가벼워집니다.
- 프롬프트 바로 위에 두면 정보 줄이 한 줄을 통째로 써서 줄바꿈이 생기지 않습니다. `below`로 프롬프트 아래에 두면 `auto mode on` 같은 모드 표시와 같은 줄을 나눠 쓰기 때문에, 넘치는 부분은 끝이 `…`로 잘립니다.
- 앱 모드는 `settings.json`의 상태줄 항목을 잠시 꺼 둡니다. 원래 설정은 따로 보관했다가 `/statusline-mode script`로 그대로 되돌립니다.
- 플러그인을 지우기 전에는 꼭 `/statusline-mode script`로 되돌리세요. 되돌리지 않고 지웠다면 [터미널 설치](#터미널에서) 한 줄로 상태줄을 다시 설치하면 됩니다.
- 플러그인으로 설치한 최신 Claude Code에서만 됩니다.
- `/statusline-install`을 다시 실행하면 상태줄 스크립트가 다시 설치되면서 앱 모드는 꺼집니다. `/statusline-update`는 스크립트만 바꾸고 방식은 그대로 둡니다.

## 8. 안 될 때

**`/statusline-...` 명령이 안 보입니다.**
- 플러그인으로 설치했는지 확인하세요. 터미널 설치만으로는 명령이 생기지 않습니다.
- 이미 열려 있던 콘솔이면 `/reload-plugins`를 입력하거나 다시 여세요.
- Claude Code를 최신 버전으로 올리세요.

**줄이 아예 안 보입니다.**
Claude Code를 완전히 닫았다가 다시 여세요. 그래도 없으면 `/statusline-install`을 한 번 더 실행하세요.

**마스코트가 안 보입니다.**
아직 안 뽑은 경우입니다. `/statusline-roll`을 입력하세요.

**마스코트가 프롬프트 아래가 아니라 상태줄 끝에 나옵니다.**
- 플러그인으로 설치했는지 확인하세요. 터미널 설치만 했다면 [설치](#1-설치)의 `/plugin` 두 줄을 입력합니다.
- Claude Code를 최신 버전으로 올리세요.
- `/statusline-place`로 위치가 `line`으로 되어 있지 않은지 확인하세요.

**앱 모드에서 정보 줄이 잘립니다.**
`below`로 두면 모드 표시와 한 줄을 나눠 써서 끝이 잘립니다. `/statusline-mode app`으로 프롬프트 위 한 줄에 두거나, 창을 넓히세요.

**플러그인을 지웠더니 상태줄이 사라졌습니다.**
앱 모드에서 지운 경우입니다. [터미널 설치](#터미널에서) 한 줄을 실행하면 다시 나타납니다.

**마스코트가 두 군데에 나옵니다.**
상태줄 스크립트가 예전 버전입니다. `/statusline-update`를 실행하고 Claude Code를 다시 여세요.

**마스코트나 대사가 잘립니다.**
터미널이 좁은 경우입니다. 창을 넓히거나, `STATUSLINE_TALK=0`으로 대사를 끄거나, `/statusline-place above`로 프롬프트 위로 옮겨 보세요.

**글자가 네모(□)나 물음표로 나옵니다.**
터미널 폰트에 그 글자가 없는 경우입니다. D2Coding, Cascadia Code, JetBrains Mono처럼 기호가 넉넉한 폰트로 바꿔 보세요.

**`5H`가 `--%`로만 나옵니다.**
Claude.ai 구독 플랜이 아니면 사용량이 내려오지 않습니다. 나머지는 정상입니다.

**색이 안 나옵니다.**
`NO_COLOR` 환경변수가 켜져 있는지 확인하세요.

**상태줄 끝의 레전드 색만 이상합니다.**
터미널이 256색까지만 지원하는 경우입니다. `STATUSLINE_TRUE_COLOR=0`으로 바꾸세요.

**설치가 됐는지 확인하고 싶습니다.**

```sh
sh ~/.claude/statusline.sh --version
```
```powershell
powershell -File ~\.claude\statusline.ps1 -Version
```

버전이 나오면 정상입니다.

## 9. 업데이트와 삭제

### 업데이트

1. 터미널에서 플러그인을 최신으로 받습니다.
   ```
   claude plugin update statusline@black-astro
   ```
2. Claude Code를 다시 열고 `/statusline-update`를 입력합니다. 상태줄 스크립트가 새 버전으로 바뀝니다.

마스코트, 위치, 정보 줄 방식(스크립트·앱)은 그대로 유지됩니다.

### 삭제

앱 모드를 쓰고 있다면 먼저 `/statusline-mode script`로 되돌립니다. 그다음 아래 순서로 지웁니다.

1. `~/.claude/settings.json`에서 `statusLine` 항목과, `hooks` 안에서 `mascot-hook`이 들어간 항목을 지웁니다.
2. `~/.claude/` 안의 `statusline.*`, `mascot*`, `statusline-cache` 폴더를 지웁니다.
3. 플러그인으로 설치했다면 `/plugin uninstall statusline@black-astro`도 실행합니다.
